# Changelog

## 1.0.0

Initial version.
## 1.0.1

- Добавлен журнал передачи и чтение последнего журнала установки.

## 1.0.2

- Установка новых экземпляров Zabbix Agent 2 в C:\zabbix.
- Защита существующей установки в другой папке от автоматического переноса.

## 1.0.3

- Восстановлен стандартный путь установки агента.
- Пакет передаётся в C:\zabbix; ключ можно сохранить в локальном хранилище браузера.

## 1.0.4

- Оформление кнопки и окна установки согласовано с интерфейсом резервного копирования.

## 1.0.5

- Добавлена кнопка заполнения названия точки по имени компьютера с транслитерацией.

## 1.0.6

- Выбор режима работы компьютера и отдельная опция мониторинга Restic.
- Для Restic в пакет включён скрипт сбора состояния заданий и подтверждённых снимков.

## 1.0.7

- При повторной установке сохраняется существующее имя узла Zabbix, если агент уже использует ключ авторегистрации.
- Проверка несовпадения ключа выполняется до изменения файлов установки.

## 1.0.8

- После успешной установки в описание устройства MeshCentral добавляется отметка Zabbix; существующий текст сохраняется.

## 1.0.9

- Установщик smartmontools 7.5 включён в пакет; GitHub для его загрузки на удалённом компьютере не требуется.
- Добавлены повторные попытки загрузки и проверка SHA-256.

## 1.1.0

- Массовая установка на выбранные устройства, отдельные результаты и журналы.

## 1.1.1

- Кнопки открытия плагина переименованы в Zabbix.

## 1.2.0

- Добавлена отдельная вкладка «Настройки» внутри окна плагина для подключения к Zabbix API (URL и API-токен).
- Добавлена настройка темплейтов (шаблонов) для алертов при подключении новых ПК: общие, для профиля «Касса / постоянный ПК», «Включается по необходимости» и при включённом контроле Restic.
- Добавлена проверка подключения к Zabbix API с валидацией вписанных темплейтов и выбором доступных шаблонов из Zabbix.
- После успешной одиночной или массовой установки агента плагин автоматически привязывает настроенные темплейты к новому узлу в Zabbix, сохраняя уже существующие шаблоны.

## 1.2.1

- Исправлена последовательность завершения канала при автоматической привязке темплейтов в одиночной и массовой установке (предотвращён преждевременный переход к следующему ПК и ложный статус «Результат неизвестен»).
