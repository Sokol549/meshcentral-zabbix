# Zabbix Installer для MeshCentral

Плагин добавляет кнопку «Установить Zabbix» в сводку устройства. Он создаёт EXE, передаёт его через MeshCentral и запускает установку Zabbix Agent 2 и smartmontools на 64-битной Windows. Установщик настраивает активные проверки, SMART, температуру ACPI и авторегистрацию с PSK.

Для установки добавьте плагин в MeshCentral по адресу config.json этого репозитория. Включите поддержку плагинов в настройках MeshCentral. Для ручной установки скопируйте файлы в meshcentral-data/plugins/zabbix и добавьте zabbix в settings.plugins.list, затем перезапустите сервер.

Для работы необходимы полный администратор MeshCentral, Windows-агент от имени SYSTEM, доступ к файловому каналу и выполнению команд, доступ Windows к GitHub и CDN Zabbix и исходящий TCP 10051. В форме укажите сервер, название точки (латиница, цифры, дефис или подчёркивание) и общий ключ авторегистрации PSK из 64 шестнадцатеричных символов. Имя узла: точка-имя_компьютера. На сервере Zabbix должна быть настроена авторегистрация с этим PSK, идентификатором kzvs-pharmacies-registration-v1 и метаданными kzvs-pharmacy-windows-v1. Успешная установка не гарантирует регистрацию: проверьте узел в Zabbix.

EXE содержит секретный ключ PSK и временно находится в памяти сервера и браузера и в системной временной папке компьютера. При обрыве файл может остаться в C:\Windows\System32\config\systemprofile\AppData\Local\Temp. Там же находится журнал ZabbixMesh-install.log. Используйте HTTPS и проверьте состояние перед повтором при неизвестном результате. Существующий агент без файла C:\zabbix\autoregistration.psk, с другим именем или ключом автоматически не мигрируется.

Полный сценарий требует проверки с работающим MeshCentral, Windows-агентом и сервером Zabbix.

Начиная с версии 1.0.2, новые установки размещают Zabbix Agent 2 и его конфигурацию в C:\zabbix; smartmontools остаётся в Program Files. Существующая установка агента в Program Files автоматически не переносится и не изменяется. Служба с другим путём также приводит к остановке установки.
