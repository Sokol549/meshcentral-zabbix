# Zabbix Installer для MeshCentral

Плагин добавляет кнопку «Установить Zabbix» в сводку устройства. Он создаёт EXE, передаёт его через MeshCentral и запускает установку Zabbix Agent 2 и smartmontools на 64-битной Windows. Установщик настраивает активные проверки, SMART, температуру ACPI и авторегистрацию с PSK.

Для установки добавьте плагин в MeshCentral по адресу config.json этого репозитория. Включите поддержку плагинов в настройках MeshCentral. Для ручной установки скопируйте файлы в meshcentral-data/plugins/zabbix и добавьте zabbix в settings.plugins.list, затем перезапустите сервер.

Для работы необходимы полный администратор MeshCentral, Windows-агент от имени SYSTEM, доступ к файловому каналу и выполнению команд, доступ Windows к GitHub и CDN Zabbix и исходящий TCP 10051. В форме укажите сервер, название точки (латиница, цифры, дефис или подчёркивание) и общий ключ авторегистрации PSK из 64 шестнадцатеричных символов. Имя узла: точка-имя_компьютера. На сервере Zabbix должна быть настроена авторегистрация с этим PSK, идентификатором kzvs-pharmacies-registration-v1 и метаданными kzvs-pharmacy-windows-v1. Успешная установка не гарантирует регистрацию: проверьте узел в Zabbix.

EXE содержит секретный ключ PSK и передаётся во временный файл в C:\zabbix. После установки он удаляется; при сбое файл может остаться. Журнал ZabbixMesh-install.log находится в C:\zabbix. Ограничьте доступ к этой папке. Если отметить «Сохранить ключ в этом браузере», PSK сохраняется в локальном хранилище браузера в открытом виде при запуске установки; снятие галочки удаляет сохранённый ключ. Он доступен другим пользователям того же профиля браузера и коду сайта MeshCentral.

Полный сценарий требует проверки с работающим MeshCentral, Windows-агентом и сервером Zabbix.

Начиная с версии 1.0.3, новые установки размещают Zabbix Agent 2 и конфигурацию в C:\Program Files\Zabbix Agent 2. Папка C:\zabbix используется для передачи пакета, журнала и служебных файлов.


В форме выберите тип компьютера: касса контролируется по отсутствию данных 30 минут в 09:00–20:00 каждый день по времени сервера Zabbix (Europe/Moscow), а компьютер по необходимости не выдаёт это предупреждение. Опция Restic добавляет сбор состояния задач и позволяет серверу привязать шаблон Restic Windows scheduled tasks active. Для подтверждения снимков сами задания Restic должны записывать backup_status.json; без этого возраст подтверждённой копии неизвестен. Изменение режима требует повторной установки с тем же именем узла. Для работы вариантов на Zabbix должны быть установлены правила KZVS profile и KZVS Restic и шаблон профиля.

При повторной установке для ранее настроенного плагином агента сохраняется его существующее имя узла Zabbix, даже если название точки в форме отличается. При несовпадении PSK или отсутствии ключа авторегистрации существующий агент не перенастраивается автоматически.

После успешного завершения установщика плагин добавляет строку Zabbix в описание компьютера MeshCentral, сохраняя существующее описание. Требуется право управления устройством; отметка подтверждает завершение установщика, но не регистрацию или поступление данных в Zabbix. При неполучении подтверждения проверьте карточку вручную.

Начиная с версии 1.0.9, проверенный установщик smartmontools 7.5 включён в создаваемый EXE. Агент Zabbix при отсутствии на компьютере по-прежнему загружается с CDN Zabbix с повторными попытками; SHA-256 проверяется перед запуском. Источник включённого установщика smartmontools: https://sourceforge.net/projects/smartmontools/files/smartmontools/7.5/ .
